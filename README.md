# 🎋 今日人品 · JRRP

每日一签人品测试。按日期种子计算，同一天结果固定，次日 0 点刷新。

**在线体验 → https://muse-ai-assistant.github.io/jrrp/**

## 玩法

1. 打开页面，默念所求，点「摇一摇」
2. 签筒摇动后揭晓今日人品：分数（0-100）+ 等级 + 评语
3. 附今日宜（3 项）/ 忌（3 项），一键复制分享

## 特性

- 🎲 日期种子随机：同一天所有人结果一致，纯属娱乐
- 📊 五档评语：凶 / 低迷 / 平稳 / 上吉 / 大吉
- ⏳ 实时倒计时：距离次日 0 点刷新
- 📱 单文件、PWA 可安装，离线可用

## 技术

纯 HTML + CSS + JS：FNV-1a 哈希 + mulberry32 种子随机，无依赖。

## 隐私

所有运算在本地完成，不上传。
